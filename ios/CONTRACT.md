# Shared implementation contract

Native iOS 17+ SwiftUI app, no cloud or AI API. User explicitly requests guided choice questions after image analysis. Local OCR provides suggestions only; chat analysis uses exported photo/manifest package + imported JSON. No automatic marketplace publishing. All user data stays local and out of Git. Swift tools 5.9, Swift language mode 5 for compatibility; Foundation-only core testable on Mac without Xcode.

## Core models (agent core owns)
Public Codable/Equatable value types, public defaulted initializers.
- ProductKind: String, Codable, CaseIterable: smartwatch, headphones, chair, supplies, other; label:String.
- Platform: vinted, kleinanzeigen, both; label.
- PriceType: fixed, negotiable, free; label.
- ItemStatus: draft, ready, published, sold, archived; label.
- Photo: id:String (SHA256), filename:String, relativePath:String, previewRelativePath:String, itemID:String?, isSelected:Bool, importedAt:Date.
- PriceSource: title:String,url:String,checked:String,price:Double?,note:String,kind:String (default asking).
- Item: id:String(UUID default),title:String,description:String,brand:String,category:String,color:String,variant:String,kind:ProductKind,condition:String,price:Double?,platform:Platform,priceType:PriceType,status:ItemStatus,coverPhotoID:String?,coverReason:String,photoOrder:[String],answers:[String:String],facts:[String],questions:[String],sources:[PriceSource],pricingNote:String,notes:String,listingURL:String,revision:Int (default 1),createdAt:Date,updatedAt:Date. Defaults empty/draft/other/kleinanzeigen/negotiable, except dates/revision.
- Library: schemaVersion:Int=1,photos:[Photo],items:[Item],defaultLocation:String="Konstanz".
- WerkstattError: Error, LocalizedError, validation(String), conflict, missing(String).
- LibraryStore (synchronous class): init(root:URL)throws; library:Library get; save(_ library:Library)throws; importPhoto(data:Data,filename:String,previewData:Data)throws->Photo; createItem(photoIDs:[String],kind:ProductKind)throws->Item; updateItem(_ item:Item,expectedRevision:Int)throws; regroup(photoIDs:[String],destinationID:String?)throws; imageURL(photoID:String,preview:Bool=false)throws->URL. Originals imported into inbox, assignment moves to bearbeitet/itemID, SHA256-based duplicates, atomic JSON persistence, no overwrite on collision, validate selection/cover and revisions. updateItem ready validation calls Questionnaire.blockers(item:photos:). Do not overwrite files outside root.

## Questions / exchange (agent flow owns, based on above models)
- QuestionChoice: Identifiable key id:String,label:String,detail:String.
- GuidedQuestion: Identifiable id:String,title:String,subtitle:String,choices:[QuestionChoice],allowsMultiple:Bool=false.
- Questionnaire.questions(for item:Item)->[GuidedQuestion], blockers(item:Item,photos:[Photo])->[String]. Answers are choice IDs keyed by question ID; multiple IDs comma-separated. Unknown/later answers never fabricate facts. Used watch: condition,function,battery,charger; chair:condition,chairRotation,chairHeight; headphones:condition,packaging and function only used; supplies/other:condition, generic function only if relevant. Battery qualitative good/notMeasured accepted; later function blocks ready. Condition user selection takes precedence over image inference. Ask only unanswered relevant questions; caller can remove an answer to re-open. Question IDs stable and public.
- ListingComposer.applyAnswers(to item:Item,location:String)->Item (derives condition and description from known facts + choices; neutral ordinary wear, names established defects, includes delivery picked in answers or pickup default).
- AnalysisExchange.requestData(item:Item,photos:[Photo])->Data throws; applyResponse(_ data:Data,to item:Item,photos:[Photo])->Item throws. Typed same-item revision-bound import, validates model, sources and cover, preserves seller answers; external questions converted to review blockers (no claim of automated vision).
- ZIPArchive.make(entries:[String:Data])->Data throws; read(_ data:Data)->[String:Data] throws. Stored standard ZIP sufficient, strict safe paths, no ignored data in repo. Used for analysis export and backup; export keeps only selected images, scrubs EXIF in native adapter.
- DetectionHints.from(text:String)->DetectionSuggestion? with kind,brand,title,color strings. Conservative OCR identification recognizes a few clear model phrases, otherwise only category suggestions; no guessed prices/function.
